Professional Self-Assessment

Throughout my time in the computer science program, I have developed knowledge and skills in software design and engineering, algorithms and data structures, databases, programming, and problem solving. Through my courses, I learned how to write code, improve programs that already exist, test my work, and think carefully about how software should be designed. This ePortfolio reflects the progress I have made in these areas and shows the skills I developed while completing my coursework. It also shows my growth as a student and how my work in the program has prepared me for a career in software engineering.

The artifact I selected for my capstone is the IT 145 Project Two artifact, Grazioso Salvare Rescue Animal System. I chose this artifact because it gave me a strong starting point to show growth in multiple areas of computer science. The original project was a Java console application created to manage rescue animals by allowing users to intake dogs and monkeys, reserve animals, and print lists of animals. Although the original artifact already included object-oriented programming concepts, it also gave me many opportunities to improve the design, organization, efficiency, and long-term usefulness of the program. By making three different enhancements to this artifact, I was able to demonstrate software design and engineering skills, algorithms and data structures skills, and database skills within one connected project.

An important area of growth in this program has been my ability to develop and improve software solutions using proper design practices. In my software design and engineering enhancement, I improved the structure of the original program by refactoring repeated code into helper methods, improving menu handling, and making input validation stronger. These improvements made the code easier to read and to maintain, and more reliable for the user. This enhancement helped me show that I can evaluate an existing program, identify weaknesses in its design, and improve it in a way that leads to better software quality. It also showed my understanding of modularity, readability, maintainability, and design that meets user needs.

Another major area of growth has been my understanding of algorithms and data structures. For my second enhancement, I improved how the program stores and processes rescue animal data by adding a shared data structure and creating helper methods for searching, filtering, and sorting animal records. These changes made the program more organized and reduced repeated logic. It also improved how data could be managed across the system. This enhancement helped me show that I understand how data structures affect the efficiency and design of a program and how algorithms can improve the way a program handles information. It also helped me see more clearly that choosing the right structure for storing and processing data can make software more scalable and easier to improve in the future.

The third enhancement gave me the opportunity to show my knowledge of databases and permanent data storage. In the original artifact, animal records remained available only while the program was running. When the program closed, the data was no longer saved. For my database enhancement, I added database functionality so animal records could be stored permanently and updated in a more reliable way. I created a database helper class that allowed the Java program to connect to the database, retrieve saved animal records, and update reservation data. This enhancement made the artifact more realistic and useful because it now supports permanent storage rather than temporary in-memory lists only. Through this enhancement, I showed that I understand how integrating a database can improve a program by making data storage more reliable, better organized, and available over time.

I further improved this database enhancement by adding a delete function that allows the user to remove animal records from permanent storage. To support this change, I added a new menu option in Driver.java, created logic that asks the user for the animal type and name, and added a deleteAnimal() method in DatabaseHelper.java to remove the record from the correct database table. This improvement made the artifact stronger by adding another important database operation and giving the user more control over stored data.

Through completing these enhancements, I also improved my ability to explain technical information to different audiences. This can be seen through my code review, my milestone narratives, and how I explain the purpose and value of each enhancement. In computer science, writing working code alone is not enough. It is also important to clearly explain design choices, justify improvements, and describe the impact of technical choices in a professional way. This ePortfolio allowed me to practice presenting my work in a way that is clear, organized, and connected to the skills and goals developed in the computer science program.

My work in this capstone also shows my growth in using tools and techniques that support the software development process. Throughout the program, I have gained experience with Java, object-oriented design, data structures, databases, and development tools that helped me in building and improving programs. In this project, I combined those skills together to analyze an existing artifact, plan meaningful enhancements, make changes, and reflect on the value of the work I completed. This process helped me clearly understand that software development is not only about writing code, but it also requires reviewing, improving, testing, and organizing software carefully.

I have also grown in my ability to think more carefully about reliability, usability, and security in software. Although this artifact is a simple rescue animal system, my enhancements still show that I understand the importance of input validation, accurate data handling, and stronger program structure. Strong input validation helps reduce errors and makes the program safer, more stable, and easier to work with. Good organization of data helps prevent logic problems and makes the system easier to manage. Adding database support also improves reliability by making sure important records are properly stored and updated correctly. These improvements show that good software development involves more than just making a program function. It also includes thinking about how the software works over time and how it can better meet user needs.

When I look back at my work in the program, I can see growth in both my technical ability and my professional development. When I first started the program, I was mostly concerned with making sure my code ran correctly. Over time, I learned that good software also depends on strong structure, efficient design, maintainability, and room for future improvement. This capstone gave me the opportunity to use these skills together in one project. It also helped me reflect on how much I have learned and how I can carry these skills into future academic or professional work.

Overall, this ePortfolio reflects my development as a computer science student and how that growth has prepared me for my software engineering career. Each part of this ePortfolio, including the code review, artifact, enhancements, narratives, and self-assessment, helps show the knowledge and skills I developed during the program. This project allowed me to demonstrate growth in software design and engineering, algorithms and data structures, databases, communication, and professional reflection. These experiences have prepared me to continue improving my skills and to contribute to software projects in a professional setting.
